## Stardew Sync v0.1.4 — Secure LAN Device Pairing & Unified Pairing Interface

This release introduces Phase 5A cryptographic peer-to-peer device pairing over the local area network (LAN), replaces separate pairing views with a unified dual-panel pairing interface, and hardens TCP socket error resilience.

### What's Changed
- **Secure LAN Device Pairing (Phase 5A)**: High-security mutual authentication between desktop devices on the local network using Ed25519 identity keypairs, X25519 ECDH key exchange, ChaCha20-Poly1305 AEAD framing, and DPAPI-encrypted trust store persistence.
- **Unified Device Pairing Interface**: A responsive dual-panel modal displaying active invitation generation (`SD-XXXX`) with live countdown alongside LAN peer selection and invitation code entry simultaneously.
- **Short Authentication String (SAS) Verification**: Deterministic 6-digit numeric SAS code with matching visual emoji set for out-of-band verification against active man-in-the-middle attacks.
- **Authenticated Remote Device Unpairing**: Cryptographically signed mutual unpair revocation protocol ensuring devices fail closed when trust is revoked.
- **TCP Connection Error Hardening**: Structured mapping for unexpected TCP stream closures without raw I/O exposure, fail-closed handling for pairing requests without an active invitation, and Windows Winsock non-blocking socket state correction.
- **Save Integrity Safeguards**: Retained strict default-deny read-only safeguards across all local farm saves and Xbox WGS containers.

### Known Limitations
- Internet peer-to-peer relaying and WAN NAT traversal are planned features and not yet supported. Only local network (LAN) device pairing is available in this release.
- Stardew Valley save files remain completely protected by read-only safeguards.
