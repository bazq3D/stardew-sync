## Stardew Sync v0.1.3 — Stability, Playtime Accuracy & Localization

This stabilization release brings complete English and Turkish application localization, fixes playtime calculations, decouples application updates from the game-running safety lock, and strengthens update reservation safety.

### What's Changed
- **Application Localization (i18n)**: Full English (`en`) and Turkish (`tr`) localization with an accessible toolbar language selector and persistent language settings.
- **Accurate Host Playtime Calculation**: Fixed an XML root-path parser defect by locating `<millisecondsPlayed>` on the authoritative host `<Farmer>` entity, properly displaying active play hours.
- **Decoupled Application Auto-Updates**: Stardew Sync software updates can now be checked, downloaded, and installed while Stardew Valley is running (save-critical operations remain strictly protected).
- **Atomic Reservation Safety & Token Ownership**: Implemented CSPRNG token-based reservation ownership and fail-closed state machines to prevent premature timeout lease eviction and race conditions.
- **Save Integrity Safeguards**: Retained strict default-deny read-only safeguards across all local farm saves and Xbox WGS containers.

### Important Notes
- Peer-to-peer save synchronization, device pairing, and live host migration are planned features and remain under active development.
- Stardew Valley save files remain completely protected by read-only safeguards.
